# Concept Home Interior — Website

Website for **Concept Home Interior**, a family furniture manufacturing business selling factory-direct to homeowners, interior designers, businesses and showrooms.

## Features
- Interactive 3D lounge chair (Three.js): drag to rotate, switch upholstery and wood finishes
- Collections shown as animated workshop line drawings with dimensions
- Four-step workshop process and sections for each customer type
- Spec sheet of materials
- Custom order form that prepares a WhatsApp message

## Files
- `index.html`: the whole site in one file (CSS and JS inline; Three.js r128 from cdnjs)
